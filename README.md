# White Noise Artifact

A white noise player web app, built with Noki — Tyler's SI agent — through artifact engineering: describing what you want in plain language and getting working software back.

## What it is

- White, pink, and brown noise, generated live in the browser (Web Audio API)
- Large play/pause control with adjustable volume
- Sleep timers: 15, 30, or 60 minutes
- Follows your system's light or dark theme
- Responsive — works on phones and desktops

## Run it

Just open `index.html` in any browser. No build step, no dependencies, no audio files — the noise is synthesized in real time. Or enable GitHub Pages on this repo to host it live.
